## 📖 Overview

**Box Link** is an enterprise-grade, offline-first Point of Sale (POS) and inventory management solution engineered specifically for the dynamic needs of Indian wholesale and retail ecosystems. Built with speed, resilience, and intelligence in mind, Box Link streamlines daily operations, from rapid billing and complex multi-unit handling to intelligent upselling.

By operating completely offline with a robust local SQLite architecture, Box Link ensures zero downtime and instantaneous transaction processing, making it the ideal solution for high-traffic retail environments.

## ✨ Core Features

*   ⚡ **Offline-First Architecture**
    Uninterrupted, lightning-fast billing and data processing with zero reliance on active internet connectivity.
*   🔍 **Phonetic & Transliterated Search**
    Advanced search engine supporting Hinglish transliteration. Type "center" or "senter" to instantly locate "सेंटर" with intelligent diacritic normalization.
*   🤖 **AI-Driven Smart Upselling**
    Proprietary 'Frequently Bought Together' recommendation engine analyzes historical sales data to provide context-aware, unit-specific upselling prompts directly on the billing interface.
*   📦 **Dynamic Multi-Unit Management**
    Seamlessly manage and bill products across wholesale and retail units (e.g., Sacks/Bora, Kilograms, Pieces) dynamically without rigid stock constraints.
*   📊 **Comprehensive Financial Ledgers**
    Real-time cashbook tracking, expense management, credit ledgers, and dynamic profit margin analysis.
*   🎨 **Modern Glassmorphism UI**
    A distraction-free, highly responsive, and aesthetically pleasing interface designed to reduce cognitive load during peak billing hours.

## 🚀 Getting Started

### Prerequisites
*   Windows 10 or later (64-bit)
*   Minimum 4GB RAM

### Installation
1.  Navigate to the latest release in this repository.
2.  Download the **`Box Link Setup 1.0.0.exe`** installer.
3.  Execute the installer and follow the on-screen prompts.
4.  Launch the application. Box Link will automatically provision the local database and launch the secure environment.

## 🛠️ Technical Stack

*   **Runtime:** Electron & Node.js
*   **Frontend:** React 18, Vite, TailwindCSS
*   **Database:** Better-SQLite3 (Local Edge Storage)
*   **Styling:** Custom Glassmorphism UI & Framer Motion

## 🔄 Updates & Versioning

Box Link utilizes an automated update-check mechanism. Refer to the `box-link-version.json` file in this repository to track current active versioning and distribution parameters.
