# Box Link POS System

Welcome to the **Box Link POS** official release directory!

## Overview
Box Link is an advanced, offline-first Point of Sale (POS) and inventory management system designed specifically for Indian wholesale and retail shops (Kirana stores). It features lightning-fast billing, intelligent transliteration search (Hinglish), smart AI recommendations for cross-selling, and comprehensive ledger management.

## Installation
1. Download the latest `Box Link Setup 1.0.0.exe` from this folder.
2. Run the executable to install the software on your Windows machine.
3. The software will automatically start and connect to the local SQLite database.

## Key Features
- 🚀 **Offline First:** Fast operations without requiring an internet connection.
- 🔍 **Smart Phonetic Search:** Search items in Hinglish (e.g., "center" correctly matches "सेंटर").
- 🤖 **AI Insights:** Provides intelligent 'Frequently Bought Together' suggestions directly during billing to increase ticket sizes.
- 📦 **Multi-Unit Wholesale Support:** Easily sell products in multiple units (Bora, Kg, Pis) with accurate tracking and pricing.
- 📊 **Comprehensive Analytics:** Track sales, cashbook, expense ledgers, and profit margins easily.
- 📱 **Glassmorphism UI:** Modern, clean, and distraction-free user interface.
